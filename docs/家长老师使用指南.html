家校留言板 · 使用指南

电脑委员 整理 · 有问题随时来教室找我

一、写给老师：我做这个的目的和效果

各位老师好，我是咱们班的电脑委员。做这个留言板，是想解决几个日常小麻烦： 家长有急事找不到老师、打电话怕打扰上课；班级群消息多，重要的事容易被刷走； 让同学带话又容易漏。

现在教室电脑桌面上常驻一块"班级留言板"，效果是这样的：

  • 家长在手机上留言，教室屏幕上出现红点提示；
  • 留言内容默认隐藏，学生点击卡片才展开——不会把任何人的消息直接晒在公共屏幕上；
  • 学生点开的那一刻，家长手机上立刻变成"已读"，不用再回复"收到了"；
  • 有需要全班马上知道的事，用紧急通知：教室电脑会全屏醒目提示，留言板里也会留档。
教室电脑桌面上的留言板：红点=未读，点击卡片才显示内容

二、家长怎么用（4 步）

① 手机浏览器打开：https://liuyan.dengjy.xyz
② 在页面顶部选择班级（选一次，下次自动记住）
③ 搜索并选择自己孩子的姓名 → 点"进入留言板"
④ 输入留言 → 点"发送"

留言状态就两种：已发送 = 已送到教室； 已读 = 教室里已经点开看过了。看到"已读"就放心吧。

看到"已读"后面跟着的日期和时间，就是孩子点开留言的确切时刻。

三、老师怎么用

  1. 打开同一个网址 → 点"我是老师" → 先选班级 → 输入自己的身份（比如"数学老师"）→ 进入；
  2. 普通模式：像家长一样给全班留言，教室留言板会出现卡片；
  3. 紧急通知：教室电脑立刻全屏醒目提示，适合"马上改集合地点"这类等不了的事；
  4. 普通留言和紧急通知在同一条历史记录里，随时能回看自己发过什么、有没有被看到。

四、小贴士

· 页面偶尔显示"已断开"不用管，它会自动重连；刷新一下也行，历史不会丢。
· 留言在教室屏幕上默认隐藏、点击才展开，隐私放心。
· 最新消息显示在列表最上面，不用往下滑着找。
· 每人最多保留最近 200 条记录，超出自动删最旧的。
· 换手机或清过浏览器缓存也没关系，历史记录在服务器上也存着，重新登录就回来。
· 打不开、看不懂的，课间来教室找我

五、设置菜单（右键面板）逐项说明

在教室留言板卡片上右键会弹出设置菜单，每一项的作用如下：

  • 班级：决定这台教室电脑订阅哪个班（8 / 10 / 13）。选一次会自动记住并重启程序生效，之后每次开机都用这个班。三台教室电脑各选各的，互不干扰。
  • 位置：换面板在屏幕上的停靠位置（右上角 / 左上角 / 右下角…），适合被桌面美化软件挡住的情况。
  • 每条留言最多显示 N 行：卡片展开后正文最多几行。数字越小卡片越窄、一屏能排的人越多；设为 0 表示显示完整内容。
  • 缩放比例：25% / 50% / 75% / 100%，按教室投影仪分辨率调大小，文字太小看不清就调大。
  • 卡片密度：标准（一屏约 11 人）/ 紧凑（约 20 人）/ 双列网格（约 40 人）。人多的班选密度高的。
  • 开机自启：勾选后教室电脑开机自动运行留言板，不用每次手动点。
  • 玻璃磨砂背景 / 重新采样：让面板背景跟随桌面壁纸做磨砂效果，"重新采样"是重新取一次壁纸颜色。

七、它是怎么工作的（技术文档）

这一节用大白话讲清楚留言板背后的运作原理。不需要任何技术背景也能看懂， 主要是帮大家理解"为什么有时消息会延迟""为什么关机后消息不丢"这些日常问题。

1. 整体架构：三段式

家长端（手机网页）→ MQTT 服务器（云端）→ 教室端（桌面挂件）

家长在手机上打开网页 → 网页连到云端的 MQTT 服务器 → 服务器把消息转发给教室电脑上的留言板程序。
反过来也一样：教室端点开留言后，"已读"回执原路发回 → 服务器 → 家长手机上显示"已读"。

MQTT 是一种专门为消息传递设计的协议，类似于"快递中转站"： 你把留言交给中转站，中转站负责送到教室。即使教室暂时关着，中转站也会帮你暂存。

2. 消息怎么走

以家长发一条留言为例，整个过程是这样的：

  1. 家长在手机上输入留言，点"发送"；
  2. 网页把留言发给 MQTT 服务器（云端），同时手机上显示已发送；
  3. 服务器把留言转发给教室电脑，留言板出现红点提示有新消息；
  4. 学生点击卡片展开留言；
  5. 教室端立刻发一条"已读"回执给服务器；
  6. 服务器把"已读"转发给家长手机，显示变成绿色的已读 + 时间。

整个链路通常在 1~2 秒内完成。如果教室电脑关着，消息会在服务器排队，开机后自动送达。

3. 消息存在哪里（不会丢的秘密）

留言板有三重存储，确保换设备、关机、断网都不会丢消息：

  • 家长手机本地（浏览器 localStorage）：家长发的每条留言都存在手机里，永不清空。 换手机或清缓存也不怕——下面的服务器备份兜底。
  • MQTT 服务器（retained 消息）：每次发消息时，网页会把一份"历史快照"上传到服务器。 服务器永远保留最后一份快照，换设备登录时自动恢复。
  • 教室电脑本地：教室端只保留当天需要显示的，每天零点自动清空（但服务器上的不删）。

所以即使教室电脑被重装系统，只要家长端还在、服务器还在，历史记录就不会丢。

4. 每日清空：为什么昨天的消息今天不见了

教室端的留言板每天零点自动清空当天显示，这主要有两个原因：

  • 公共屏幕上不宜长期展示旧留言（隐私）；
  • 每天看当天的新消息更清晰，不会被旧消息淹没。

但家长端永不清空——你在手机上随时能翻看以前发过的所有留言和已读记录。 如果教室关机时家长发了消息，这条消息会留在服务器的快照里，教室开机后自动恢复出来。

注意：服务器免费版的会话保持只有 2 小时，教室关机超过 2 小时后， 排队消息会被丢弃。但历史快照不受影响——它永远保留最后一份， 所以即使排队消息丢了，家长下次发消息时快照会补上之前未读的那条。

5. 多班级隔离：三个班怎么互不串扰

三个班共用同一个服务器和同一个网页，靠的是消息通道加班级编号来隔离。

打个比方：8 班的消息走"8 班通道"，10 班的走"10 班通道"，13 班的走"13 班通道"。 每个班只收自己通道里的消息，不会被别的班看到。具体来说：

  • 家长登录时选了哪个班，消息就发到哪个班的通道；
  • 教室端在设置里选了哪个班，就只订阅哪个班通道的消息；
  • 每个班的历史记录也在各自的通道里分开存。

所以即使三台教室电脑同时开着，也不会互相干扰。

6. 隐私与安全

  • 留言内容默认隐藏：教室屏幕上只显示姓名和红点，内容必须点击才展开—— 不会把任何家长的话直接晒在公共屏幕上。
  • 服务器密码加密：连接服务器的用户名和密码在软件里是加密存储的， 打包后用记事本打开配置文件看到的是乱码，不能直接读取。
  • 不收集个人信息：留言板只传输留言文字本身，不采集位置、设备信息等。

7. 教室端桌面挂件

教室电脑上的留言板不是普通窗口，而是桌面层挂件——它"贴"在桌面上， 像壁纸的一部分一样常驻显示：

  • 其他窗口可以正常盖住它（不会挡住老师用电脑讲课）；
  • 按 Win+D 显示桌面时它会自动出现（1 秒内回来）；
  • 右键可以调出设置菜单：选班级、换位置、调密度、调缩放、开机自启等。

如果教室装了 ClassIsland 软件，老师的紧急通知还能触发 ClassIsland 全屏醒目提示。

8. 常见疑问

为什么有时候消息发出去很久才显示"已读"？
可能是教室电脑关着或者网络不稳定。消息会在服务器排队，教室开机联网后自动送达。 如果超过 2 小时教室还没开，排队消息会被丢弃，但下次家长发消息时历史快照会补上未读的那条。

教室端看不到某个班的留言怎么办？
八成是设置里班级选错了。右键面板 → 班级 → 选对本班，程序会自动重启一次，之后就正常了。

家长端选了别的班能看到别的班的留言吗？
不能。每个班的消息走独立通道，选了哪个班就只看哪个班的消息和历史。

换手机或清理了浏览器缓存，历史会丢吗？
不会。手机本地存储清了没关系，服务器上还存着历史快照。重新登录同一通道就自动恢复。
